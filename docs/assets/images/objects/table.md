Create ONE standalone game stimulus asset: an unmistakable ordinary rectangular wooden dining TABLE with a flat tabletop and four straight legs, three-quarter view, entirely visible and centered in a square canvas with modest margins. No chairs, no objects on top, no logs, no text, no symbols, no faces. Match the supplied sprite atlas STYLE ONLY: handmade textured paper cutout, subtle risograph grain, warm natural brown wood, simple clean readable silhouette, friendly pictogram illustration.
